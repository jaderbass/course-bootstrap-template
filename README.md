# Bootstrap 5.3 – Responsive Webdesign mit Framework

Dieses Repository enthält Unterrichtsmaterialien, Codebeispiele und Übungen zum **CSS-Framework Bootstrap 5.3**.

Die Beispiele vermitteln schrittweise, wie sich mit vorgefertigten CSS-Klassen und Komponenten responsive Webseiten effizient gestalten lassen.

## Kursinhalte

- Einführung in Bootstrap und CSS-Frameworks
- Einbindung von Bootstrap über CDN oder lokale Dateien
- Das responsive Grid-System mit Containern, Zeilen und Spalten
- Breakpoints und responsive Layouts
- Utility-Klassen für Farben, Abstände, Größen und Ausrichtung
- Typografie und Buttons
- Gestaltung von Tabellen und Bildern
- Formulare und Formularkomponenten
- Cards zur Darstellung strukturierter Inhalte
- Responsive Navigationsleisten (Navbar)
- Interaktive Komponenten wie Modals
- Verwendung des Bootstrap-JavaScript-Bundles
- Anpassung des Frameworks mit eigenen CSS-Regeln
- Individuelle Gestaltung von Bootstrap mit Sass

## Entwicklungsumgebung

Die Beispiele sind für die Arbeit mit **Visual Studio Code** vorgesehen.

Bootstrap 5.3 kann entweder über ein CDN oder über lokal gespeicherte CSS- und JavaScript-Dateien eingebunden werden.

Für die Anpassung mit Sass wird die Erweiterung **Live Sass Compiler von Glenn Marks** verwendet. Die Kompilierung wird über **Watch Sass** in der Statusleiste von VS Code gestartet.

## Übungen

Die Beispiele und Übungen zeigen, wie sich mit Bootstrap responsive Webseiten aufbauen und gestalten lassen.

Neben dem Grid-System stehen die praktische Verwendung von Cards, Formularen, Navigationsleisten und weiteren Komponenten im Mittelpunkt.

Ein zusätzlicher Workshop behandelt die Einbindung und individuelle Anpassung von Bootstrap mithilfe von Sass.

## Weiterführende Kursmodule

Die Kursmaterialien sind in eigenständige Repositories aufgeteilt:

- HTML5 & CSS3 – Grundlagen
- CSS Flexbox
- CSS Grid
- Sass (SCSS)
- **Bootstrap 5.3**

## Hinweise

Die Beispiele sind teilweise bewusst vereinfacht, um einzelne Bootstrap-Techniken und Komponenten verständlich zu demonstrieren.

Einige interaktive Komponenten benötigen das Bootstrap-JavaScript-Bundle.

Die Materialien basieren auf **Bootstrap 5.3**. Änderungen späterer Hauptversionen werden nicht berücksichtigt.

Die Materialien dienen Unterrichts- und Übungszwecken.

Weitere Informationen bietet die [offizielle Bootstrap-Dokumentation](https://getbootstrap.com/docs/5.3/).
